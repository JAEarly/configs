# configs

Personal configuration files for terminal tools.

## Contents

- **alacritty/** - Alacritty terminal emulator configuration
- **zellij/** - Zellij terminal multiplexer configuration and themes
- **setup.sh** - Setup script to symlink configs to ~/.config

## Setup

```bash
./setup.sh
```

This will:
- Create necessary config directories
- Download Catppuccin Mocha theme for Alacritty
- Symlink configuration files to ~/.config
